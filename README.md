# DIU Sports Management System

## 📌 Project Overview

The **DIU Sports Management System** is a C programming project designed to manage sports-related information in a simple and organized way.

The system helps manage **teams, players, sports, and matches**. It is developed as an academic project for the **Data Structures course** at **Daffodil International University (DIU)**.

The main purpose of this project is to demonstrate how basic **Data Structures and C programming concepts** can be applied to solve a real-world management problem.

---

## 🎯 Objectives

* Manage different sports teams.
* Store and manage player information.
* Organize sports and team records.
* Manage match information.
* Track match status and records.
* Provide a simple and user-friendly management system.
* Demonstrate the practical use of data structures in C.

---

## ⚙️ Features

### 👥 Team Management

* Add a new team.
* Store team name and sport name.
* Display available teams.
* Manage team records.

### 🏃 Player Management

* Add players to teams.
* Store player name and jersey number.
* Associate players with their respective teams.
* Display player information.

### 🏆 Match Management

* Create and manage match records.
* Store participating teams.
* Track match status.
* View match information.

### ↩️ Undo Concept

The system demonstrates the concept of **Undo**, where a previous operation can be reversed.

This concept helps demonstrate how data structures can be used to maintain and restore previous states of a system.

---

## 🧠 Data Structures Used

The project demonstrates several fundamental concepts of Data Structures:

* **Structures (`struct`)** — used to organize team, player, and match information.
* **Linked List** — used for dynamically storing and managing records.
* **Pointers** — used for connecting nodes and manipulating dynamic data.
* **Dynamic Memory Allocation** — used to allocate memory when required.
* **Stack Concept** — used to demonstrate the Undo operation.

## ▶️ How to Run

### Using GCC

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Compile the program:

```bash
gcc main.c -o sports_management
```

4. Run the program:

### Windows

```bash
sports_management.exe
```

### Linux / macOS

```bash
./sports_management
```
